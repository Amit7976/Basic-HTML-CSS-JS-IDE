# 🧑‍💻 Basic HTML, CSS & JS IDE

A **lightweight in-browser code editor** that lets you write and preview HTML, CSS, and JavaScript in real-time! Perfect for beginners, quick testing, or playing around with code without installing anything.

🌐 **Live Demo**: [Try It Now](https://amit7976.github.io/Basic-HTML-CSS-JS-IDE/)

---

## ✨ Features

- 📝 Built-in editors for HTML, CSS, and JavaScript
- ⚡ Live preview updates instantly as you type
- 🎨 Clean and simple layout
- 📱 Fully responsive – works on mobile too!
- 🧠 Great for practicing, testing, or learning web development basics

---

## 🛠️ Tech Stack

- HTML5  
- CSS3  
- JavaScript (Vanilla)

> No libraries. No frameworks. Just core web tech 💪
